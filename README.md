# 🚗 BMW Elite Motors — Luxury Showroom Website

> A premium, fully responsive dealership website for BMW Elite Motors — where passion meets precision.

🔗 **Live Demo:** [https://yuossef-ashry.github.io/BMW-Showroom/](https://yuossef-ashry.github.io/BMW-Showroom/)

---

## 📖 About The Project

**BMW Elite Motors** is a high-end, immersive dealership landing page built to replicate the feel of a real luxury automotive showroom online. Every design decision — from typography to color palette to layout — reflects the prestige and performance identity of the BMW brand.

The project demonstrates advanced front-end skills through a multi-section, single-page experience that guides visitors from discovery all the way to booking a test drive.

---

## ✨ Sections Overview

| Section | Description |
|---------|-------------|

| 🏆 **About** | Brand story with stats — 15+ Years Experience, 50+ Award Wins |
| 🛠️ **Services** | 6 premium service cards: Test Drive, Financing, Concierge, Tuning & more |
| 🖼️ **Gallery** | Auto-scrolling image showcase — "The Art of Engineering" |
| 💬 **Testimonials** | 3 verified client reviews from M4, X5 M, and 7 Series owners |
| 📞 **Contact** | Lead capture form with model selector + showroom info |

## 🚀 Getting Started

```bash
# 1. Clone the repository
git clone https://github.com/yuossef-ashry/BMW-Showroom.git

# 2. Navigate into the project
cd BMW-Showroom

# 3. Open in your browser
open index.html
```

No dependencies or build tools required — pure HTML, CSS & JS.
